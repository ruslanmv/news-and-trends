## What Happened

Claude Code's Projects feature allows users to run multiple AI agents in the cloud under the same roof, with a shared memory, goals, and library of files and artifacts. Each project has "threads" running different tasks in parallel, with a "coordinator" directing everything. This new feature allows users to manage complex AI workflows more efficiently and effectively.

This new release is particularly noteworthy because it allows users to run multiple agents using the same set of processes and resources, which can improve performance and scalability. Additionally, it provides new features such as the ability to set custom goals for each project and store artifacts outside the container.
