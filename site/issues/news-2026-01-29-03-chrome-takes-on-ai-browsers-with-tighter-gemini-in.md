## What Happened

Chrome is taking on AI browsers with a tighter Gemini integration and an agentic feature for AI Pro and Ultra users. This integration will make it easier for developers to integrate AI features into their Chrome extensions and apps. The new Gemini integration will allow developers to easily access and use AI features from AI browsers like Google Colab and ChatGPT within their Chrome extensions and apps.

The new feature will also provide developers with more control over how AI features are used in their extensions and apps. This will allow them to create more secure and reliable AI solutions.

## Why It Matters

This new feature is important because it will make it easier for developers to build and deploy AI-powered Chrome extensions and apps. This will lead to a more diverse and vibrant ecosystem of AI-powered Chrome extensions and apps.

This feature will also allow developers to create more secure and reliable AI solutions. By giving developers more control over how AI features are used, this feature can help to prevent malicious use of AI.

## Context & Background

Chrome is already one of the most popular web browsers in the world, and it has a large and active developer community. The new Gemini integration and agentic feature are designed to make it easier for developers to build and deploy AI-powered Chrome extensions and apps. This feature is also expected to boost the adoption of AI-powered Chrome extensions and apps, which could lead to a more significant market share for Chrome.

The new Gemini integration and agentic feature are expected to be rolled out in Chrome 85. Developers can learn more about the feature by reading the article on TechCrunch.
