## What Happened

ScreenAI is a new visual language model that can understand and generate natural language in a visual format. It is designed to be used in user interfaces (UI) and visually-situated language understanding (VSLU) applications.

The model has been developed in collaboration between Google AI and the University of Washington. It is said to be the most accurate VSLU model to date.

ScreenAI can understand complex natural language instructions that are represented in images. This means that users can interact with AI systems using visual cues, such as pointing and clicking.
