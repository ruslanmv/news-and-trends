## What Happened

GitHub has just added Claude and Codex AI coding agents directly into GitHub. This means that users with a Copilot Pro Plus or Copilot Enterprise subscription can now access these AI coding tools directly within the platform.

The new feature is part of Agent HQ, GitHub's vision to make AI development and management more accessible to developers. This move is aimed at streamlining the AI development process and making it easier for developers to build and deploy AI solutions.

## Why It Matters

This feature is a major milestone in the development of AI within GitHub. It will make it easier for developers to create and deploy AI solutions, which will have a significant impact on the future of software development. 

By adding Claude and Codex AI coding agents, GitHub is giving developers more flexibility and control over their AI development. This will allow them to build more complex and powerful AI solutions, which will in turn lead to better software products and services.
