## What Happened

Anthropic has introduced an "auto mode" for its Claude Code, a new tool that lets AI make decisions on users' behalf. The feature offers vibe coders a safer alternative between constant handholding or giving the model dangerous levels of autonomy.

This mode allows users to set parameters and have Claude Code make decisions based on those parameters. For example, users can set Claude Code to make decisions on their commute home, or to control their home security system. The company says the feature can help to reduce the burden on users and to improve the safety of their homes.

## Why It Matters

The auto mode is a significant feature for a few reasons. First, it can help to reduce the burden on users. By automating some of the decision-making processes, Claude Code can save users time and effort. Second, the auto mode can help to improve the safety of users' homes. By giving users a way to set up the tool to make decisions that are safe, the company can help to reduce the risk of unauthorized access or other security breaches. Third, the auto mode can open up new possibilities for creative applications of AI. By allowing users to set up the tool to make decisions in different ways, the company can explore new ways to use AI to solve problems.
